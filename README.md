# 产教智对 · 专业动态适配智能分析系统

静态展示版，纯前端单页，无需后端、无需数据库。

## 是什么

面向财经类院校「专业—岗位—技能—课程」动态适配的分析系统，包含 12 个模块：

| 模块 | 内容 |
|---|---|
| 作品导览 | 首屏与八模块入口 |
| 实证研究 | 研究总览、四步研究链、真人体验 |
| 岗位证据 | 岗位原文、任务拆解、训练转译 |
| 从业者体验 | 原话保留与训练设计改动 |
| 培养方案数据库 | 62 份方案、院校对照与检出状态 |
| 研究生档案 | 66 条项目与真实去向（6 个视角） |
| 数据与口径 | 证据、导入与更新 |
| 岗位适配方案 | 24 专业、72 工作包与方案总览 |
| 动态方案生成 | 参数调整与逐轮反思 |
| 效果验证 | 反事实与三种情景、24 专业覆盖 |
| 风险与治理 | 预警、证据与模拟检查 |
| 个性化 & 意见反馈 | 导入岗位文本与反馈收集 |

## 打开方式

直接访问 Pages 网址即可，手机、电脑都能看，不需要安装任何东西。

本地打开：双击 `index.html`。

## 说明

- 页面内的「最欠缺的技能」为自建便利样本（访谈 12 人、社交平台话题 40 条、岗位描述 60 条），提及率不等于全行业统计。
- 效果验证部分的数值由模拟参数产出，不是就业率或满意度。
- 交互功能（滑块调参、运行优化、CSV 导入、导出）在静态版中保留为展示态。

## 更新

替换 `index.html` 后重新推送即可，Pages 会自动重新构建。
